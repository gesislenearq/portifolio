# Portfólio Geise Moura

Este projeto é um portfólio estático de design de interiores e arquitetura.

## Estrutura do projeto

- `index.html` — página principal do portfólio
- `css/styles.css` — estilos globais e responsivos
- `js/main.js` — lógica de filtro e lightbox
- `imgs/` — imagens dos projetos e recursos visuais

## Como usar

1. Abra `index.html` no navegador.
2. Mantenha a pasta `imgs/` no mesmo nível de `index.html`.
3. Para adicionar novos projetos, use o bloco existente em `index.html` e atualize o array `PROJECTS` em `js/main.js`.

## Próximos passos sugeridos

- Usar nomes de imagem sem espaços para evitar problemas de caminho.
- Separar os ativos de branding em uma pasta `assets/` se quiser organizar melhor.
- Adicionar controle de navegação móvel ou um menu hambúrguer para telas pequenas.
